# «Стальной Штурм» на Яндекс Играх — от А до Я

## Что уже сделано в игре

**Веб-версия.** Игра собирается под браузер. Используется шаблон Godot 4.7.2 «расширения без потоков»:
страницы Яндекс Игр не дают браузеру режим SharedArrayBuffer. C++-библиотека SteelCore собрана под
WebAssembly (`native/bin/libsteelcore.web.wasm32.wasm`, Emscripten 4.0.11), поэтому бой в браузере
идёт так же, как на телефоне. Маршруты ботов в вебе считаются прямо в шаге боя, по три за шаг, без
отдельного потока.

**Размер — 97,0 МБ** при лимите площадки 100 МБ. Архив ZIP весит 55,5 МБ. Чтобы уложиться, атласы
37 готовых моделей в вебе хранятся в WebP (`assets/models/web`, 13 МБ): иначе они лежали бы дважды,
в двух форматах сжатия для видеокарт (по 52 МБ). В Android-сборку WebP не попадает, а в веб — PNG.

**SDK Яндекс Игр** (`web/yandex_shell.html` + узел `Yandex` в `scripts/yandex.gd`):

| Что | Когда |
|---|---|
| `YaGames.init()` | сразу при открытии страницы, параллельно с загрузкой игры |
| `LoadingAPI.ready()` | когда ангар показан впервые и игрой уже можно пользоваться |
| `GameplayAPI.start()` | когда закрыт брифинг и начался бой, и при снятии паузы |
| `GameplayAPI.stop()` | на паузе, по окончании боя, при выходе в ангар |
| полноэкранная реклама | при выходе из боя («В АНГАР», «ЕЩЁ БОЙ», «ПОКИНУТЬ БОЙ») — логическая пауза; как часто показывать, решает площадка (не чаще раза в минуту) |
| реклама за награду | кнопка «▶ РЕКЛАМА: ЕЩЁ +N СЕРЕБРА» на экране итогов: серебро за бой ещё раз; кнопка видна, только если SDK работает |
| звук | выключается на время рекламы, при скрытой вкладке и по событию площадки `game_api_pause` |
| пауза | бой ставится на паузу, если реклама или площадка просят паузу |
| сохранения | прогресс пишется и в браузер, и в облако игрока (`player.setData`, не чаще раза в 2 с); при запуске из облака берётся более свежая версия — с Яндекс ID можно продолжить на другом устройстве |

**Страница:**
- SDK подключён как `<script src="/sdk.js">` — так Яндекс отдаёт его игре на площадке.
- Отключены контекстное меню, выделение текста, прокрутка и «резинка» страницы.
- Тексты загрузчика — на русском.

**Управление на ПК.** Работают все функции:
- WASD — езда;
- Q/E или стрелки — камера;
- пробел — огонь;
- 1/2/3 — снаряжение;
- Shift или правая кнопка мыши — снайперский прицел;
- Esc или P — пауза;
- мышь — как палец на телефоне.

**Шрифт.** В браузере нет системных шрифтов, а во встроенном шрифте Godot нет стрелок → ▶ ▸ ◀. Их
даёт маленький шрифт `assets/fonts/symbols.ttf` (кусочек DejaVu Sans).

**Как проверялось.** Игра запускалась в Chromium с подделкой SDK (`build/web4/sdk.js`), которая пишет
каждый вызов в консоль. Порядок вызовов верный:
1. init, затем загрузка облака;
2. ангар, затем LoadingAPI.ready;
3. брифинг закрыт — GameplayAPI.start, пауза — GameplayAPI.stop;
4. «Покинуть бой» — полноэкранная реклама, после её закрытия ангар;
5. реклама за награду — событие «награда» дошло до игры.

Ангар грузится ~16 с, бой ~5 с — это программная графика контейнера; на нормальной видеокарте быстрее.
Обычная версия (ПК, Android) не изменилась: без SDK реклама просто не показывается.

## Что сделать тебе

### 1. Консоль разработчика
1. Войди с Яндекс ID на https://games.yandex.ru/console и заполни данные разработчика.
2. Чтобы получать деньги за рекламу, заключи договор на вкладке монетизации. Нужен статус
   самозанятого, ИП или юрлица в России; точный порядок консоль покажет сама.
3. «Добавить приложение» → тип «Игра».

### 2. Загрузка игры
- Файл: `SteelAssault_yandex.zip`. Внутри всё лежит в корне, `index.html` тоже в корне, в именах
  файлов нет пробелов и русских букв.
- Загружается на вкладку «Черновик» (раздел с архивом игры).
- Ориентация: **только горизонтальная**.
- Платформы: **компьютеры и мобильные** (планшеты тоже). На ТВ не включать: пульт игра не
  поддерживает.

### 3. Монетизация
- Включи рекламу РСЯ: полноэкранная и за вознаграждение. По правилам она включена по умолчанию.
- Липкий баннер (sticky) — по желанию, настраивается в консоли без изменений в игре. Я бы начал
  без него: на телефоне он закрывает часть экрана с кнопками.

### 4. Карточка игры
Тексты — в `texts.md`, картинки — в `promo/`:

| Поле | Файл / значение |
|---|---|
| Иконка | `promo/icon_512x512.png` (512×512, квадрат без скруглений) |
| Обложка | `promo/cover_800x470.png` (800×470; та же картина, что на иконке) |
| Скриншоты | `promo/screenshots/*.jpg` — 7 штук, 1920×1080 (16:9): Берлин, Сталинград, Нормандия, Эль-Аламейн, Прохоровка, Арденны, ангар |
| Язык | русский (игра только на русском — другие языки не отмечай) |
| Возраст | 12+ |
| Категории | основная — «Экшен» (или «Стрелялки», если есть), вторая — «Симуляторы» |

Размеры иконки, обложки и скриншотов (512×512, 800×470, 16:9) я брал из справок и разборов
разработчиков: сайт Яндекса из моего окружения не открывается. Перед отправкой сверь их с
подсказками в самой консоли. Если нужен другой размер, могу перерендерить.

### 5. Модерация
1. Отправь черновик. Модерация обычно занимает 3–5 рабочих дней.
2. Если пришли замечания, пришли их мне: поправлю игру или материалы и соберу новый архив.

## Риски, о которых стоит знать

- **Символика.** На немецких танках прямой крест (балкенкройц), как в «Мире танков»; свастики нигде
  нет. Если модератор всё же попросит, могу заменить знак на номер или убрать.
- **Иконка и обложка.** Это постановочный рендер из движка игры (своя сцена: закат, Т-34-85, «Тигр»
  в дыму, название), а не скриншот. Если модерация потребует «нарисованную» иллюстрацию, её лучше
  заказать художнику; размеры и название останутся теми же.
- **Слабые телефоны.** Веб-версия тяжелее приложения: тот же 3D, но через WebGL. На слабых телефонах
  в ангаре стоит включить «ЭКОНОМИЯ» и «ЧЁТКОСТЬ 60 %».
- **Т-34/76.** На башне чёрные пятна — дефект атласа самой модели. Он есть и в Android-версии, к вебу
  отношения не имеет. На скриншоты этот танк не попал.
- **Размер 97 МБ** — запас до лимита 3 МБ. Если что-то добавлять (новые танки), атласы в вебе можно
  ужать сильнее.

## Как пересобрать

```
# C++ под все платформы (веб — нужен Emscripten 4.0.11)
EMSDK=путь/к/emsdk ANDROID_NDK_ROOT=путь/к/ndk sh tools/build_native.sh
# веб-версия
cd godot && godot --headless --export-release "Web" ../build/yandex/index.html
cd ../build/yandex && zip -9 -r ../SteelAssault_yandex.zip .
```

Шаблоны экспорта Godot 4.7.2 должны включать `web_dlink_nothreads_release.zip`. Атласы для веба
пересоздаёт этот скрипт:

```
python3 - <<'PY'
from PIL import Image; import glob, os
for p in glob.glob('godot/assets/models/*.png'):
    k = os.path.basename(p)[:-4]
    Image.open(p).convert('RGBA').save(f'godot/assets/models/web/{k}.webp', 'WEBP', quality=72, alpha_quality=50, method=5)
PY
```
