# Публикация «Стального Штурма» в RuStore — пошагово

Всё, что нужно загрузить, лежит в папке `store/` и в собранном APK. Шаги в консоли делаете вы: вход,
подтверждение личности и отправка на модерацию — только от владельца аккаунта.

## Что приготовлено

| Что | Где |
|---|---|
| APK 4.3.1 (arm64, подпись v2+v3, 179 МБ, своя иконка) | `build/SteelAssault.apk` — отправлен в чат |
| Иконка 512×512 (та же картинка, что на телефоне: `godot/icons/`) | `store/icon_512.png` |
| 7 скриншотов 1920×1080 | `store/screens/` |
| Название, краткое и полное описание, категория, возраст, «Что нового» | `store/listing_ru.md` |
| Политика конфиденциальности | `docs/privacy.html` → ссылка после шага 1 |
| Ключ подписи и пароль | `steel4.keystore` + `sign.env` — отправлены в чат, **сохраните в надёжном месте** |

## Шаг 1. Ссылка на политику конфиденциальности (GitHub Pages, 2 минуты)

1. github.com → репозиторий **CloudeCode** → **Settings** → **Pages**.
2. **Source**: Deploy from a branch. **Branch**: `claude/mobile-tanks-game-m3lge6` (или `main`, если сольёте
   ветку), папка **/docs** → **Save**.
3. Через минуту-две страница откроется по адресу
   `https://gggbro216-sketch.github.io/CloudeCode/privacy.html` — проверьте в браузере.

## Шаг 2. Аккаунт разработчика

1. Откройте **console.rustore.ru**, войдите (VK ID / Сбер ID / другой предложенный способ).
2. Выберите тип разработчика. Для бесплатной игры без покупок подходит физическое лицо; статус ИП/юрлица
   нужен только для приёма платежей (с 1 февраля 2026 года).
3. Заполните данные и пройдите проверку личности по инструкции консоли, примите соглашение разработчика.

## Шаг 3. Новое приложение

1. «Создать приложение» → загрузите `SteelAssault.apk`. Имя пакета — `com.steelassault.game`, его потом не
   поменять.
2. **Подпись.** RuStore не переподписывает APK: ключ `steel4` — подпись игры навсегда. Все обновления
   подписываются только им, поэтому файл ключа и пароль нужно хранить вне этого рабочего контейнера:
   облако, флешка, менеджер паролей. Плюс: у тех, кто уже поставил APK вручную, игра обновится из RuStore
   поверх (подпись та же).

## Шаг 4. Карточка (тексты — из `store/listing_ru.md`)

- **Название**: «Стальной Штурм» — ровно как под иконкой на телефоне (частая причина отказа — расхождение).
- **Краткое и полное описание** — копируйте из файла как есть.
- **Иконка** — `icon_512.png` (та же, что на телефоне: модерация сверяет).
- **Скриншоты** — все 7 из `store/screens/`, по порядку; ориентация горизонтальная.
- **Категория** — Игры → Экшен. **Возраст** — 12+.
- **Политика конфиденциальности** — ссылка из шага 1.
- **Контакты для пользователей** — почту укажите сами (я её в файлы не вписывал).

## Шаг 5. Модерация

Отправьте на проверку. Обычно она занимает от нескольких часов до пары рабочих дней. Если придёт отказ —
пришлите мне текст причины, поправлю.

## Обновления

1. Я поднимаю `version/code` (сейчас 37) и собираю APK тем же ключом.
2. В консоли: «Новая версия» → загрузить APK → «Что нового» → на модерацию.

Ключ хранится только в `build/` контейнера, а он одноразовый. В новой сессии понадобятся ваши сохранённые
`steel4.keystore` и `sign.env`: пришлите их, и я положу их в `build/` перед сборкой.
